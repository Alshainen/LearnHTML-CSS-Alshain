## ⏭️ Kenapa Ada yang Dilewati?

6 lesson di atas nggak dibuatkan folder praktik terpisah. Sebagian besar bukan karena belum ditonton, tapi karena konsepnya udah lebih dulu dipakai sendiri di project lain sebelum videonya sampai ke situ:

- **Flexbox** & **Icons** — udah dipakai jauh lebih dulu dan cukup fasih di project tantangan (lihat [tantanganCode4 DONE](./tantanganCode4%20DONE)) serta project lain di luar repo ini
- **Navigation Bar** & **Website Layout** — polanya udah dipraktikkan langsung lewat layout sidebar + header di project yang sama
- **Height & Width** — kepakai berulang-ulang secara implisit di hampir semua lesson CSS lain, jadi nggak dibuatkan folder sendiri
- **Image Gallery** — yang ini paling jujur belum ada bukti kuat udah dikuasai di project manapun. Kandidat paling masuk akal buat ditonton ulang suatu saat.
